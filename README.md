## 项目简介

AI Novelist 是一个面向 AI 编程助手（WorkBuddy / Claude Code 等）的长篇小说创作技能（Skill）。它不是简单的"输入一句 Prompt 生成一段续写"工具，而是一套完整的**工程化创作工作流**——系统化管理设定、长期记忆、伏笔追踪、节奏控制，让 AI 成为协作编辑部而非全自动代笔。

### 核心理念

小说创作的本质难点从来不是文笔，而是**长线约束管理**：

- 人设不能前后割裂
- 世界观设定不自相矛盾
- 前文埋设的伏笔需要呼应
- 第 17 章自述怕水的配角，不能在第 83 章毫无心理负担跃入河水
- 主角第五章确立的目标，需要持续贯穿五十章的剧情走向

仅依靠单次 Prompt，根本无法维系长篇的稳定逻辑。本技能将创作流程拆解为六个阶段，配合文件级长期记忆和六步质量门禁，从根源上解决 AI 长篇创作的记忆遗忘与逻辑崩塌问题。

## 核心特性

| 特性 | 说明 |
|------|------|
| **六阶段创作流程** | 初始化 → 交互构思 → 规划确认 → 流水线写作 → 质量门禁 → 归档回写 |
| **五层协同记忆** | 质量门禁 + RAG 剧情检索 + 知识图谱 + 大纲锚点 + 跨 Agent 审核 |
| **六步质量门禁** | 更新记忆 → 一致性检查 → 风格校准 → 去 AI 味校稿 → 节奏审查 → 门禁检查 |
| **三级伏笔追踪** | 战略级 / 战役级 / 战术级，自动追踪埋设、回收、超期预警 |
| **节奏三档制** | 慢档（铺垫）/ 中档（升温）/ 快档（突破），配额硬上限防止剧情加速 |
| **去 AI 味润色** | 两遍式润色：第一遍清除 7 类 AI 模式，第二遍 AI 自审残留问题 |
| **题材风格矩阵** | 9 大题材（玄幻/修仙/都市/科幻/历史/悬疑/言情/恐怖/轻小说）自动配置写作参数 |
| **断点续写** | 检测未完成项目，自动恢复到中断位置 |
| **多写作模式** | 逐章串行（默认）/ 子 Agent 并行 / Agent Teams 协作 |

## 安装

### 方式一：WorkBuddy 用户（推荐）

将本仓库克隆到 WorkBuddy 技能目录：

```bash
git clone https://github.com/JIRBOY/ai-novelist.git ~/.workbuddy/skills/ai-novelist
```

安装后，当对话中出现"写小说""创作故事""续写章节"等关键词时自动触发。

### 方式二：Claude Code 用户

将仓库克隆到 Claude Code 的技能目录：

```bash
git clone https://github.com/JIRBOY/ai-novelist.git ~/.claude/skills/ai-novelist
```

### 方式三：手动安装

下载 ZIP 包，解压到你的 AI 助手技能目录中，确保 `SKILL.md` 位于技能根目录。

## 快速开始

### 1. 开书

在 AI 对话中输入：

```
帮我开一本修仙小说
```

或使用命令：

```
开书
```

AI 将引导你完成三层递进式问答：

- **L1 核心定位**（必答）：题材创意、主角设定、核心冲突
- **L2 深度定制**（可选）：世界观、叙事视角、核心主题、读者定位、章节数量
- **L3 标题生成**：AI 生成候选标题，你选择或自定义

### 2. 继续写

确认大纲后，日常推进只需一句：

```
继续写
```

AI 会自动完成：写前分析 → Beat Sheet → 扩写 → 合成 → 润色 → 六步门禁。

### 3. 查看状态

```
伏笔状态
角色状态
体检
```

## 铁律（Iron Law）

以下约束无论用户如何要求，均不得绕过：

1. **禁止跳过开书前确认** — 必须完成五要素确认（目标读者、写作风格、核心禁区、自动化等级、目标规模）
2. **禁止跳过章节闭环** — 每章生成后必须执行六步门禁
3. **禁止混淆正文与元信息** — 正文中不得出现 `[说明]`、`TODO`、写作分析段落
4. **禁止门禁失败后继续写作** — 门禁未通过时唯一合法操作是执行修复流程
5. **禁止任意修改主线规划** — 改纲须显式执行改纲流程并经用户确认
6. **禁止剧情加速** — 每章至多触发 A/B/C 配额 1 项

## 适用场景

- **中文网文长篇连载**：支持百万字级别持续创作，自动管理伏笔和人物状态
- **长篇小说创作**：系统化管理世界观、人物弧光、剧情一致性
- **系列短篇**：共享世界观和角色档案的系列故事创作
- **创作教学**：标准化的创作流程帮助新手理解小说结构

## 技术特点

### 低上下文策略

- 写前默认只读 2 个核心文件（`novel_plan.md` + `novel_state.md`）
- 单章前置读取上限 4 个文件
- RAG 检索只返回 Top-K 片段，不回读整章
- 每 10 章做一次深度压缩与风格校准

### 人机协同模式

AI Novelist 坚持人机协同创作理念：人掌控方向与审美，AI 承担记忆、执行、校验等重复性工作。AI 可以完成扩写、素材补充、逻辑校验、持续陪跑，但决定故事内核的关键判断仍需人把控。
