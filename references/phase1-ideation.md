# Phase 1：交互式构思

## 三层递进式问答

### Layer 1 — 核心定位（必答，3 问）

#### Q1：题材与创意

```
📝 Q1：题材与创意
   ○ 悬疑推理   ○ 现代言情   ○ 奇幻玄幻   ○ 科幻未来
   ○ 武侠仙侠   ○ 历史架空   ○ 都市现实   ○ 恐怖惊悚
   ○ 轻小说     ○ 🎲 随机生成

   也可以直接描述你的想法，比如"一个关于记忆商人 detective 的故事"
```

用户选择题材后，AI 基于 `genre-matrix.md` 自动加载该题材的风格模板、节奏参数、爽点配置。

#### Q2：主角设定

```
📝 Q2：主角设定
   ○ 男性主角   ○ 女性主角   ○ 双主角     ○ 群像戏

   主角的核心特质是什么？
   ○ 冷静智慧   ○ 热血冲动   ○ 隐忍腹黑   ○ 正直善良
   ○ 亦正亦邪   ○ 🎲 随机生成
```

#### Q3：核心冲突

```
📝 Q3：核心冲突
   ○ 生死存亡   ○ 查明真相   ○ 复仇雪恨   ○ 成长突破
   ○ 爱情阻碍   ○ 权力争夺   ○ 守护保护   ○ 命运抗争
```

### Layer 2 — 深度定制（可选，5 问）

#### Q4：世界观

```
📝 Q4：世界观设定（可选，跳过则按题材默认）
   故事发生在什么世界？有什么特殊规则？
   例："近未来都市，人类可以通过技术交易记忆"
```

#### Q5：叙事视角与基调

```
📝 Q5：叙事视角与基调
   视角：
   ○ 第一人称   ○ 第三人称限知   ○ 第三人称全知   ○ 多视角切换
   基调：
   ○ 紧张冷峻   ○ 轻松幽默   ○ 悲壮厚重   ○ 温暖治愈   ○ 黑暗压抑
```

#### Q6：核心主题

```
📝 Q6：核心主题（可选）
   你希望故事探讨什么主题？
   ○ 人性善恶   ○ 自由与秩序   ○ 爱与牺牲   ○ 成长与蜕变
   ○ 复仇与救赎   ○ 科技与伦理   ○ 命运与选择   ○ 🎲 随机
```

#### Q7：读者定位

```
📝 Q7：读者定位
   ○ 网文大众（追求爽感与节奏）
   ○ 类型读者（偏好特定题材深度）
   ○ 文学读者（重视文笔与深度）
   ○ 泛娱乐读者（平衡可读性与品质）
```

#### Q8：章节数量

```
📝 Q8：章节数量
   ○ 短篇（10-15章）   ○ 中篇（20-30章）   ○ 长篇（50-100章）
   ○ 超长篇（100+章）   ○ 自定义

   每章字数偏好：
   ○ 精简（2000-3000字）   ○ 标准（3000-5000字）   ○ 厚重（5000-8000字）
```

### Layer 3 — 标题生成

基于已收集的创意元素，AI 生成 3-5 个候选标题：

```
📝 标题候选
   1. 《午夜记忆商》— 悬疑感强，直指核心设定
   2. 《遗忘交易》— 简洁有力，留有想象空间
   3. 《记忆深渊》— 暗示深度与危险
   4. 自定义标题

   选择编号或输入自己的标题：
```

## 五要素确认卡

所有问答完成后，生成确认卡并写入 `00_memory/idea_seed.md`：

```markdown
# 创作种子

## 五要素确认

| 要素 | 确认值 |
|------|--------|
| 目标读者 | 网文大众 / 类型读者 / 文学读者 |
| 写作风格 | 网文爽文 / 历史正文 / 文艺 / 悬疑推理 / 言情细腻 |
| 核心禁区 | 不能写什么（敏感题材、读者雷点） |
| 自动化等级 | 手动（每章确认）/ 半自动（每10章确认）/ 全自动 |
| 目标规模 | 总字数、预期卷数、单章字数范围 |

## 故事定位

- 题材：{genre}
- 主角：{protagonist_type} — {protagonist_trait}
- 核心冲突：{core_conflict}
- 世界观：{world_setting}
- 视角：{pov}
- 基调：{tone}
- 核心主题：{theme}
- 章节数：{chapter_count}
- 单章字数：{words_per_chapter}
- 标题：{title}
```

用户确认后进入 Phase 2。
