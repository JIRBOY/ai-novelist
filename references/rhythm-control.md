# 节奏控制与反向刹车

## 节奏三档制

长篇小说的节奏控制是核心质量指标。采用三档制管理每章节奏：

### 慢档（铺垫/羁绊）

- **特征**：主线零推进，聚焦人物关系、世界观展示、情感积累
- **频率**：每 3-4 章至少 1 章
- **功能**：
  - 深化角色关系
  - 展示世界观细节
  - 为后续高潮蓄势
  - 读者情绪缓冲
- **要求**：
  - 必须有微型冲突（非零冲突）
  - 必须埋设至少 1 个伏笔
  - 章末悬念可以为"弱"但不可以为"无"

### 中档（次要矛盾升温）

- **特征**：次要矛盾升温未爆发，主线有微推进但不实质改变
- **频率**：占比 ≥60%
- **功能**：
  - 保持读者兴趣
  - 推进支线剧情
  - 逐步逼近核心冲突
  - 积累信息差
- **要求**：
  - 有明确冲突场景
  - 章末悬念至少"中"

### 快档（主线突破）

- **特征**：主线格局发生实质性改变
- **频率**：每卷 ≤2-3 次
- **功能**：
  - 核心爽点释放
  - 主线矛盾推进
  - 重大转折
- **要求**：
  - 快档后下一章必须是慢档或中档缓冲
  - 每章至多触发 A/B/C 中 1 项

## A/B/C 配额系统

### 定义

| 配额 | 含义 | 触发条件 |
|------|------|----------|
| A | 主线矛盾实质推进 | 主线格局发生实质性、不可逆的改变（非小摩擦） |
| B | 主要关系决定性升级 | 主要角色关系到达决定性节点（结盟/决裂/告白/宣战等） |
| C | 核心秘密完整揭露 | 核心秘密在本章被完整揭露（非暗示） |

### 规则

- **每章至多触发 1 项**：同时触发 ≥2 项 = 越界，Beat Sheet 必须修改后重写，门禁强制失败
- **触发后冷却**：A 触发后 2 章内不可再触发 A；B 触发后 1 章内不可再触发 B
- **快档章节**：触发 A/B/C 后，下一章必须是慢档或中档
- **非终局章节**：禁止解决主线核心冲突

## 事件矩阵与冷却

防止剧情模式化（主角走到哪都踩人）：

| 事件类型 | 说明 | 冷却期 |
|----------|------|--------|
| `conflict_thrill` | 冲突爽点 | 2 章 |
| `bond_deepening` | 人物羁绊 | 1 章 |
| `faction_building` | 势力经营 | 2 章 |
| `world_painting` | 风土人情 | 3 章 |
| `tension_escalation` | 危机升级 | 2 章 |
| `power_up` | 力量提升 | 3 章 |
| `reveal_minor` | 次要秘密揭露 | 1 章 |
| `setback` | 主角受挫 | 2 章 |

**规则**：刚用过的类型在冷却期内不得作为主 Beat。每 5 章必须至少出现一次羁绊或风土人情。

## 章末强制自检

每章写作完成前，强制回答两个问题：

1. **主线核心矛盾仍未解决？** — 非终局章节必须为"是"
2. **章末具体悬念是什么？** — 不得模糊，必须用一句话描述

## 反向刹车机制

解决 AI 过度"帮助解决问题"的倾向：

1. **非终局章节禁止解决主线核心冲突**
2. **每章必须新增至少一个未解决的次要问题**
3. **章末必须留下悬念钩子**（疑问型/危机型/转折型）

## 悬念钩子类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 疑问型 | 抛出新的疑问 | "那封信上只写了三个字：你输了。" |
| 危机型 | 角色陷入即时危险 | "门被撞开的瞬间，他看到了不该看到的东西。" |
| 转折型 | 出人意料的转折 | "她转过身，发现站在身后的，竟然是已经'死去'三年的父亲。" |
| 信息差型 | 读者知道角色不知道的信息 | "他不知道的是，电话那头的人，此刻就站在他身后。" |

## 节奏监控

系统自动监控节奏健康度：

- **连续高压超过 3 章** → 提醒插入慢档
- **连续平淡超过 2 章** → 提醒推进冲突
- **连续 5 章无羁绊或风土人情** → 提醒补充
- **快档后未缓冲** → 门禁失败

## 大纲锚点与进度配额

```json
{
  "total_chapters": 100,
  "current_chapter": 35,
  "current_arc": "第二卷：京城风云",
  "chapters_in_arc": 30,
  "quota": {
    "min_progress": 0.34,
    "max_progress": 0.36
  }
}
```

每章写前读取全局进度条，动态注入约束：
- "当前第 35 章，距离目标还有 65 章，本章严禁超过当前节点剧情"
- 越界直接触发门禁失败

## 冲突值量化

为每章分配冲突值（1-5 星）：

| 星级 | 说明 | 频率限制 |
|------|------|----------|
| ★★★★★ | 峰值章节（卷高潮/全书高潮） | 每卷 1-2 次 |
| ★★★★ | 高冲突章节 | 每卷 3-5 次 |
| ★★★ | 中冲突章节 | 常规 |
| ★★ | 低冲突章节 | 常规 |
| ★ | 缓冲章节 | 每 3-4 章 1 次 |

**奇点事件**：临时挂起力量上限的破格章节，全书 ≤2 次，需特殊标记。
