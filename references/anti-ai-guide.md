# 去 AI 味润色指南

## 核心原理

AI 文本之所以"有 AI 味"，是因为大语言模型的统计算法倾向于选择"在最多情况下都说得过去"的表达——导致文字安全、中性、可预测，缺乏人类写作的具体性和个人性。

**去 AI 味不是删词，而是用具体细节替代抽象套话，用行动替代状态描述。**

## 两遍式润色流程

### 第一遍：清除 AI 模式

逐段扫描，针对以下 7 类模式逐一处理。

#### 1. AI 高频词汇（直接替换）

| 词/短语 | 问题 | 改法 |
|---------|------|------|
| 不禁 | 剥夺角色主动性 | 直接写角色的行动 |
| 仿佛/宛如/宛若 | 过度比喻 | 用具体感知描写替代 |
| 映入眼帘 | 陈词滥调 | 直接写看到了什么 |
| 心中暗道/暗自思忖 | 内心独白套话 | 删除或改为行动 |
| 不由得 | 被动反应 | 写出主动动作 |
| 一时间 | 模糊时间 | 用具体动作填充时间 |
| 与此同时 | 论文式过渡 | 用场景切换替代 |
| 值得注意的是 | 论文腔 | 直接陈述事实 |
| 毫无疑问 | 武断判断 | 用证据说话 |
| 事实上 | 口头禅 | 删除，直接说 |
| 总的来说 | 总结腔 | 删除 |
| 令人印象深刻 | 空洞评价 | 写出具体印象 |
| 仿佛一切都在 | 模糊概括 | 写出具体的"一切"是什么 |

#### 2. 弱化副词（删除或替换）

| 副词 | 问题 | 改法 |
|------|------|------|
| 似乎 | 模糊不确定 | 要么确定，要么不写 |
| 好像 | 模糊比喻 | 直接写看到的 |
| 大概 | 模糊程度 | 给出具体数字或删除 |
| 或许 | 模糊可能 | 角色要么做要么不做 |
| 也许 | 同上 | 同上 |
| 几乎 | 模糊接近 | 写出具体差距 |
| 稍微 | 模糊程度 | 具体描述程度 |
| 确实 | 多余强调 | 删除 |

#### 3. 意义膨胀（精简）

| 膨胀表达 | 精简为 |
|----------|--------|
| 在某种程度上 | （删除） |
| 从某种意义上说 | （删除） |
| 就...而言 | （删除） |
| 需要指出的是 | （删除） |
| 众所周知 | （删除或具体化） |
| 在这个过程中 | （删除） |
| 基于...的考虑 | 因为... |

#### 4. 通用套话（替换为具体描写）

| 套话 | 改法 |
|------|------|
| 在这个关键时刻 | 写出具体的"关键"是什么 |
| 一切都变了 | 写出具体变了什么 |
| 气氛变得紧张 | 写出紧张的具体表现（动作、表情、声音） |
| 时间仿佛静止 | 写出具体的静止感（声音消失、呼吸可闻） |
| 命运的转折点 | （删除，让事件自己说话） |
| 内心深处 | （删除，用行动表现内心） |

#### 5. 论文结构（打破）

- 删除"首先""其次""最后""综上所述"等过渡词
- 打破"三段式"论述结构
- 避免"一方面...另一方面..."的对称结构
- 消除"总—分—总"的论述框架

#### 6. 正式语体（口语化）

| 正式语体 | 口语化 |
|----------|--------|
| 对...进行了... | 直接写动作 |
| 被...所... | 直接写 |
| 给予了...高度评价 | 夸了... |
| 做出了...贡献 | 帮了... |
| 采取了...措施 | 做了... |

#### 7. 排比三连（打破节奏）

- 检测三段式排比（A、B、C 三个结构相同的句子）
- 打破其中至少一段的节奏
- 避免对仗过于工整的句式
- 用长短句交替制造自然节奏

### 第二遍：AI 自审

完成第一遍后，对修改稿提问：
> "这段文字哪些地方还是明显 AI 生成的感觉？"

列出 3-5 条具体问题，再次修改后输出最终版。

**自审检查清单**：
- [ ] 每个角色说话方式是否有区分度？
- [ ] 是否有足够的具体细节（而非抽象概括）？
- [ ] 句长是否有变化（非全部中等长度）？
- [ ] 是否有"万能过渡句"残留？
- [ ] 情绪表达是否通过行动而非陈述？
- [ ] 开头是否有套路化模板？
- [ ] 结尾是否有过度总结？

## 最小化改动原则

- 只改有问题的地方，不破坏原有叙事
- 不为了"去 AI 味"而过度改写
- 保留作者（用户）的独特表达
- 保持章节的核心剧情和情感不变
- 改动后字数变化不超过 ±10%

## 去 AI 味评分

润色后进行量化评分：

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| AI 词汇残留 | 30% | 0=无残留, 1=1-3处, 2=4-6处, 3=7+处 |
| 具体性 | 25% | 0=高度具体, 1=较好, 2=一般, 3=抽象居多 |
| 句式多样性 | 20% | 0=丰富, 1=较好, 2=一般, 3=单调 |
| 角色声音 | 15% | 0=高度区分, 1=较好, 2=一般, 3=同质化 |
| 过渡自然度 | 10% | 0=自然, 1=较好, 2=一般, 3=生硬 |

**评分等级**：
- 0-0.5：优秀，可直接定稿
- 0.6-1.0：良好，微调后定稿
- 1.1-1.5：及格，需局部修改
- 1.6+：不及格，触发重写
