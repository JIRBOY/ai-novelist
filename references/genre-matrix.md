# 题材风格矩阵

## 概述

按题材自动配置写作风格、节奏模板、爽点密度、对话占比。用户选择题材后，系统自动加载对应参数。

## 风格强化模块

按需加载的风格参考文档（不一次性压进同一层提示）：

| 模块 | 适用场景 | 核心技法 |
|------|----------|----------|
| 幽默 | 轻松题材 / 缓冲章节 | 反差、自嘲、荒诞、语言游戏 |
| 悬念 | 悬疑 / 惊悚 | 信息控制、误导、延迟揭示 |
| 推理 | 悬疑 / 侦探 | 线索铺设、逻辑链、公平推理 |
| 爱情 | 言情 / 情感线 | 暧昧张力、细节心动、推拉节奏 |
| 恐怖 | 恐怖 / 惊悚 | 氛围营造、未知威胁、生理反应 |
| 奇幻 | 玄幻 / 奇幻 | 设定展示、力量体系、世界观沉浸 |
| 文学 | 文艺向 | 隐喻、留白、语言质感、主题回响 |

**加载原则**：先读模块核心，只有章节真正需要时才展开更深技法。支持主风格与辅助风格协同，但不把所有风格一次性压进同一章。

## 风格蒸馏

用户可提供参考作品（样章），AI 提取其风格 DNA：

- **句长基线**：平均句长、句长分布
- **段落节奏**：段落长度模式
- **感官偏好**：偏重视觉/听觉/触觉
- **比喻指纹**：比喻类型和频率
- **对话风格**：对话长度、语气词使用
- **禁忌清单**：该风格避免使用的表达

蒸馏结果存入 `01_settings/writing-style.md`，后续章节自动应用。
